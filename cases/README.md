# Cases

Benchmark cases do not exist yet. No cases are generated during bootstrap.

The Stage 0 package can deterministically generate the authorized allocation in
memory for mechanical tests. No experimental case set has been generated,
reviewed, frozen, or written here.

Creating the real 80-case artifact remains a later, separately controlled step
with a frozen seed and template bank, independent pre-score review, evaluator
agreement, and case-set hash.

Calibration and held-out generation must remain separated as required by
Protocol v1.0.
